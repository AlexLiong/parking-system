# 报表与计费口径

本文统一费率、计费、自动结算、统计周期和 CSV/PDF 导出口径。实现：`server/billing/calculator.py`、`server/report/reports.py`、`server/report/pdf.py`、`server/gateway/api_admin.py`。

## 1. 费率字段

`fee_rule` 当前版本字段：

| 字段 | 含义 |
|---|---|
| `free_minutes` | 免费时长（分钟） |
| `first_hour_price` | 首小时一口价（元） |
| `unit_minutes` | 首小时后计费单位（分钟） |
| `unit_price` | 每计费单位价格（元） |
| `daily_cap` | 每自然日封顶（元/天） |
| `ne_discount` | 新能源折扣（绿牌乘数，默认 0.9） |
| `round_up` | 不足一个计费单位是否进位 |
| `effective_from/created_at` | 生效/创建时间；历史版本按生效时间推导 `effective_to` |

费率变更生成新版本；记录按进场时 `fee_rule_id` 快照计费，历史账单不因新费率改变。

## 2. 计费算法

对一条正常在场记录：

1. `total_minutes = ceil((exit - entry)/60s)`，负数按 0。
2. 白名单/月租（`benefit_type=white|monthly`）直接 0 元，写免费明细。
3. `total_minutes <= free_minutes`：0 元。
4. 否则扣除免费时长，首 60 分钟按 `first_hour_price`；其后每 `unit_minutes` 按 `unit_price`，不足一单位按 `round_up` 决定进位。
5. 单日封顶：按 **UTC+8 固定业务自然日** 计算跨越天数，`cap_total=daily_cap×天数`；超过则封顶。
6. 绿牌新能源：`amount = round2(gross × ne_discount)`；其他颜色不打折。
7. 金额四舍五入到分（2 位小数）。

> 当前 `daily_cap` 的“自然日”固定 UTC+8，不做多时区；统计/展示默认 `Asia/Shanghai`。

## 3. 自动结算与人工纠正

- 正常有记录车辆出口识别成功：写 `exit_photo` → 按费率自动 `billing.pay(method=auto)` → 生成 PaymentRecord（含 0 元）→ `PaymentCompleted` → out/释放/开闸；无需剧本 pay/人工。
- 自动结算失败转人工；无记录不静默 auto，转 `exit_without_record` 待办。
- 重复/迟到的出口事件：同一 vehicle_id/plate 在 120s 窗口内且无新的 open 记录时，按已结算幂等处理（`status=settled, idempotent=true`），不新增待办/异常；有新的 open 记录则正常走流程。
- `POST /api/manual/correct-exit`：对开放记录纠正车牌/入场 sim 时间后按正常规则自动结算；无记录 `action=auto` → 409 `no_parking_record`，`free/void` + reason 走临时处置。
- 黑名单出场：0 费用、0 普通记录；遗留开放记录置 abnormal、释放车位、写审计。
- 剧本 `/api/pay` 对已自动结算记录幂等返回，不重复扣费。

## 4. 支付方式与展示

| 存储值 | 展示 |
|---|---|
| `auto` | 自动扣费 |
| `mock_scan` | 扫码支付 |
| `cash` | 现金 |
| `free` | 免费 |
| `monthly` | 月租 |

CSV/PDF 导出使用中文标签；preview 原始数据保留存储值，前端按需翻译。

## 5. 统计周期与 anchor

`GET /api/reports/preview?period=day|week|month|quarter|year&anchor=YYYY-MM-DD`：

| period | anchor 含义 | 返回层级 |
|---|---|---|
| day | 当天 | `vehicle_day`：当天汇总+车辆明细 |
| week | 该周周一所在周 | `day`：7 天汇总+每天车辆明细 |
| month | 月首日所在月 | `week`：周汇总（无车辆） |
| quarter | 该季度首月 1 日所在季度 | `month`：3 个月汇总 |
| year | 年初所在年 | `month`：12 个月汇总 |

- 只统计完整记录：`status=out AND entry_time IS NOT NULL AND exit_time IS NOT NULL`；aborted/黑名单 abnormal 不计。
- 汇总：`count_in` 入场落在区间；`count_out`/`revenue`/`avg_minutes` 出场落在区间；营收为对应 PaymentRecord.amount_paid；`peak_occupancy` 用完整记录进出扫描线。
- `limit` 默认 500/最大 2000，只截断车辆明细；汇总/周月聚合始终完整，`truncated=true` 时 PDF 顶部提示。
- 非法 period/anchor 返回 422。

## 6. CSV/PDF 导出

- `GET /api/reports/export.csv?period=&anchor=`：UTF-8 BOM，中文表头；day/week 车辆明细，month 周汇总，quarter 使用 `months`（表头 月份/进场车次/出场车次/营收），year 月汇总。
- `GET /api/reports/export?period=&anchor=`：PDF；
  - day/week：横向 A4，明细表 `Paragraph(CJK)`、时间拆日期+时间两行、`LongTable(repeatRows=1)` 分页重复表头；
  - month/quarter/year：纵向 A4，周/月汇总表；
  - 支付方式中文、顶部区间 `YYYY-MM-DD HH:MM ~ YYYY-MM-DD HH:MM`；
  - 当前 PDF 为摘要+汇总+明细表，**不包含图表**；统计页面有 Canvas 图表。
- 两个导出端点公开下载（见 docs/08），只含完整记录，不含照片/令牌/密码。
- PDF 使用每请求唯一临时文件（`data/reports` 下 mkstemp + 原子 rename + UUID），响应后清理；并发下载/导出互不覆盖。CSV 直接流式返回。

## 7. 导出语言与文件名

两个导出端点支持 `lang=zh|en`（默认 `zh`；非法值 422）：

| lang | CSV | PDF |
|---|---|---|
| `zh`（默认） | `report_<period>_<anchor>_cn.csv` | `report_<period>_<anchor>_cn.pdf` |
| `en` | `report_<period>_<anchor>_en.csv` | `report_<period>_<anchor>_en.pdf` |

- 中文/英文切换只影响表头、PDF 标签、支付方式展示；**车牌、时间、金额、车位号等数据值不做翻译**，ISO/时间格式不变。
- CSV 仍为 UTF-8 BOM（Excel 友好）；PDF 版式/分页/横向或纵向规则不变。
- 管理端英文 UI 自动传 `lang=en`；中文默认或显式 `lang=zh`；不传 `lang` 时默认中文，兼容旧调用。
- `lang` 只影响导出展示；报表统计口径不变（只完整记录、五周期、下限/汇总规则见上文）。
- PDF 仍用每请求唯一临时文件 + 原子 rename + 响应后清理；并发下载互不覆盖。

## 7. 常见口径误区

- 2520s 是源 JSON `t+duration` 的合计；当前 `duration` 语义为“入口闸→出口闸总时长”，HUD/播放总长为 **2529s**（加 9s 入口估计），不要混用。
- 仿真业务时间：demo 模式记录/报价/待办按 `business_now=epoch+sim_time`；`created_at` 仍是真实墙钟。
- 自动结算不是“免费”：0 元也会生成 0 元 PaymentRecord（method=auto），用于审计。
- 报表的“完整记录”不含黑名单 abnormal 记录；黑名单 0 费用另走审计。
- 新能源折扣只对绿牌；白名单/月租直接 0 元，不叠加折扣。
