## 3. E2E 23 个脚本

- 每个脚本独立临时 DB/服务/端口；真实浏览器（Edge/Chromium）+ 隔离后端。
- 运行：`tools/ci.py --browser-only --keep-going --scripts "<列表>"`；可选 `--soak-seconds`、`--browser-retries`、`--browser-timeout`。
- 专项脚本：`p1-hold-pdf.cjs`、`admin-p2.cjs`、`sim-p3.cjs`（P1/P2/P3），不替代 23 回归。

## 4. 常用命令

```sh
# 后端
.venv/bin/python -m pytest tests -q
.venv/bin/python tools/ci.py --bench

# Node
node --test web/sim3d/test/
node --test web/admin/test/

# 真实浏览器（先 npm ci/Playwright，必要时 CHROMIUM_PATH）
.venv/bin/python tools/ci.py --browser --soak-seconds 600
.venv/bin/python tools/ci.py --browser-only --scripts "barrier,pause,traffic"
```

Windows 使用 `.venv\Scripts\python.exe` 和相应 Node 路径；每个浏览器场景使用独立临时 DB/端口，不动主演示库。

## 5. 未覆盖与限制

- 无正式代码覆盖率百分比；以功能/接口/场景测试与 23 E2E 为主，不以覆盖率数字替代验收。
- PR-2 实拍识别精度不声称；本轮基于 expected 先验/演示图库/上传口径。
- 真实硬件（闸机、地感、摄像头）未接；摄像头/道闸故障通过注入/恢复脚本验证。
- 两小时 RSS/长稳曾失败或非单调；不能声称零泄漏。
- Windows 的完整 browser-matrix 未跑；macOS/Linux 原始包、Docker、PyInstaller 证据见 docs/03。
- 公网/鉴权 RTSP 未测；loopback 已测。
- 负载/一致性以 20/50 并发、10 万条统计基准为主，不是生产容量证明。
- 未做正式渗透/安全审计；安全边界见 docs/08。
