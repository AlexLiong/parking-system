# 演示与交付说明

1. 使用本地 `config.yaml` 新建本地库，运行启动脚本；打开/admin登录，检查80余位与设备状态。
2. 打开/sim，点击“重置”调用 `POST /api/demo/reset {force:true}`：清空当前场景、开放记录作废、保留已完成历史、pending/车位/3D 同步复位；不会再因闸区占用/未决动作返回 409（force=false 仍安全校验）。
3. 播放默认六车剧本：**t 为唯一时间轴**（同 t 按列表序），默认 6 车（E1 粤F4K1CZ blue、E2 贵JD8H5PF green、E3 鄂ABWTXHF green_large、E4 桂ES6EKB yellow、E5 甘N35MYY blue、E6 渝GDKLV32 green），源 JSON `t+duration` 合计 **2520s**；当前 `duration`（入口→出口总时长）下 HUD/播放总长 **2529s**（含入口估计 9s），覆盖免费/收费/多车/复杂路径。HUD 显示已入场/已出场/总车次、预计入场/出场/缴费；播放中锁播放、完成“↻ 重播剧本”，播放中也可手动派车。车辆到停止线由入口/出口 LPR 相机渲染 1280×720 截图识别（外部模板车牌），expected+0.85 自动放行；排队/跟车按 GLB Box3 视觉尺寸（P2-17，2.159/1.898m）。首帧已预热。
4. **速度/业务时间**：速度滑块/接口范围 **0.25–10**；demo 模式下记录时间、报价、待办超时、人工时间均按仿真时间（`business_now=epoch+sim_time`），暂停冻结；可用 10× 快速观察停车 600 仿真秒后出场，报价按 13 分钟、真实墙钟远小于仿真。`entry_sim_sec/exit_sim_sec/duration_sim_sec` 可在记录/快照/报价查看。
5. **手动派车**：点“＋ 手动派车”打开独立 modal，输入 7/8 位车牌（如 `粤F4K1CZ`），选 `blue/green/green_large/yellow` 与时长（分钟/仿真秒）；`/api/sim/dispatch-plan` 用外部 140 模板渲染车牌图并返回 `vehicle_kind`，同牌在场/排队前置 `duplicate_plate`，后端 409 `duplicate_entry`；3D 贴后端图、按类型选车型、入库后按仿真时长自动出场。失败在 modal/HUD 显示 code/reason。
6. **设备控制与异常人工处理**：正常态监控页只常显「设备控制」卡（入口/出口道闸抬/落/故障/恢复，摄像头故障/恢复，共 12 个物理按钮）；待确认/异常时才出现人工业务卡。正常有记录车辆出口自动结算；无记录/识别异常时用 `correct-exit` 选开放记录、纠正车牌/入场 sim 时间或 free/void；人工授权 API 仍保留但不在正常态常驻。
7. **黑名单/重复**：黑名单入口发 entry_denied，不建 pending/普通记录；无后车时入口杆保持 CLOSED、黑名单车在杆外倒车（reverse→close，不穿杆）；有后车时入口 OPEN→场内绕行→出口 OPEN→离开→双杆 CLOSED，后车自动重识别入库；全程仅 incident/recognition/blacklist_gate 审计。重复派车由 modal 前置拒绝/后端 409，保证 1 车 1 记录；剧本同牌时段重叠保存 422。
8. **演示剧本编辑**：管理端“演示剧本”页按 t 时间轴编辑 `vehicles`（vid/t/plate/plate_type/duration），显示预计入/出/缴、duration≈分钟；同牌时间窗重叠拒绝；保存 `PUT /api/admin/scenario`、重置内置；页面只写 JSON，不控制 3D 播放。
9. “车牌识别”页面是上传识别演示：上传整车/近景图片后显示结果/置信度/候选/耗时/原图/裁剪图；**不调用入场/放行/人工授权，不写停车记录、不占车位、不抬杆**。上传模式无 expected，只展示结果；写 `recognition_log`（返回 `recognition_log_id`）。视频识别 `tools/recognize_video.py`/`POST /api/recognize/video`；本地视频+loopback RTSP 已实测，公网/鉴权未测。
10. 记录页检查报价/付款（sim 字段）、异常页无需刷新；道闸手动操作/导出在监控页；3D 入口/出口屏显示余位/照片（P2-01/P2-02）。
11. **面板/事件流**：手动派车 modal；#control/#hud/#freeboard/#recognition-input/#scenario-progress 可拖拽、最小化、位置持久；事件/错误解包 data/payload，未知事件不丢，`<details>` 可展开时间/类型/车牌/门/金额/原因/图片；键盘 Enter/Space。
12. 管理端可切英文（`localStorage['parking.admin.locale']='en'`），9 个主要页面英文、≤800px 无横向溢出（P3-11）；加载失败有统一错误卡/Retry（P2-10）。
13. 布局演示注意：当前只读场地固定 80 位、每区 20；C25/自定义坐标仍 409，**C25 预演/validate/layout_constraints 已删除**，不要演示“C20→25 热更新”或旧“预演”按钮；真正 C25 仍暂缓/部分。保留期清理默认开启（7天/2GiB/每目录50），生产前先 `tools/cleanup_photos.py --dry-run`。
14. 若升级/替换前端后仍看到旧车牌文字/旧相机/旧说明，先对 `/sim/` 强制刷新（Ctrl+F5）或清站点缓存；正常 `/sim/` 默认 3D 相机截图识别，`?camrec=0` 回退旧图库、`?preview=1` 预览不抓拍；车牌 UV V 轴已修正。
