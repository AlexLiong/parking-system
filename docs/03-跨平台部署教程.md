# 跨平台部署与迁移

## 源码

Python 3.11–3.14兼容范围，推荐3.14精确锁；**本根目录版本已应用 Windows UTF-8/中文路径补丁，Windows 3.13 中文路径实测 283 pytest passed（增量前）；当前本机 pytest 451 passed（2026-11-08 报表双语后，_qa_audit/repair_tasks_20261108/BACKEND/evidence/full_pytest_after_i18n.log）**；交付原始包当时仅实测 macOS arm64/Linux arm64。保留 `parking-system` 与 `assets_3d` 同级，按README启动。Python依赖是`requirements.lock.txt`（UTF-8 BOM）；需其他版本解析兼容依赖时用 `tools/run.py --compatible-deps`。不要额外安装PyPI hyperlpr3（已随包提供代码，会引入另一套OpenCV）；模型/字形/模板已本地打包，无系统中文字体要求。ReportLab使用内置CID字体，Matplotlib延迟加载。

演示配置允许演示登录，非演示配置 `config.production.yaml` 首启生成随机管理员密码/密钥；`.env.example`不自动读取。监听默认127.0.0.1；局域网共享需显式host与CORS配置。关闭demo不会轮换旧账号密码。

## 识别数据与模型

运行演示不依赖下载真实数据集：随包 `datasets/external/chinese_license_plate_generator`（MIT，blue/yellow/green_car/green_truck 共 **140** 套模板+字体，固定 commit `df4757f…`；`server/lpr/render.py` 直接引用，不复制/不改上游）与 `server/lpr/plate_city_codes.json`（31省/**406** 合法发牌机关字母，无 I/O）均为运行依赖。随包 `datasets/demo-lpr`（2026-10-25 用外部模板重生成的 18 张：蓝5/小绿5/大绿4/黄4 + manifest，960×640）用于车牌贴图/历史照片；HyperLPR3 ONNX 与可选真实字符复核模型（`server/lpr/models/real_char_knn.npz`、`real_char_templates/`）均已本地打包。`config.yaml` 的 `paths.plates_dataset` 指向 `datasets/demo-lpr`；旧合成图库 `datasets/plates` 已删除。3D 仿真入口/出口场景相机来自 `assets_3d/layout/lot_v2.json` 的 `props.lpr_cameras`（入口/出口 FOV30），截图写入 `data/photos/camera/`；上传演示写入 `data/photos/uploads`、`data/photos/crops`，data 目录需可写。仿真自动通过依赖 `expected_plate` 先验与 `lpr.sim_conf_threshold=0.85`；上传演示没有 expected，只展示结果、不触发放行（`lpr.conf_threshold=0.85`）。EasyPR/treeandgrass 真实数据仅用于上传演示验证与可选字符复核，不是运行依赖。使用 `config.production.yaml` 时请确认 `paths.plates_dataset` 指向 `datasets/demo-lpr`（旧配置若仍写 `datasets/plates` 已不存在）；PR-2 不属于本轮演示/上传验收口径，不声称。

## 仿真时钟与重置

demo 模式（`config.yaml`）下业务时间 `business_now=epoch+sim_time`：记录 `entry_time/exit_time`、报价、待办超时、人工时间均按仿真时间，新增 `entry_sim_sec/exit_sim_sec/duration_sim_sec` 加性列，`created_at` 仍为真实墙钟；speed 0.25–10，暂停冻结。非 demo（`config.production.yaml`）继续真实 UTC，行为不变。重置：

```powershell
# force API（服务运行中；默认 force=false 不安全仍 409）
POST /api/demo/reset  {"force": true, "request_id": "..."}
# 离线 CLI（不需要后端运行）
.\.venv\Scripts\python.exe tools\run.py --reset       # 仅开放记录 aborted，保留完成历史
.\.venv\Scripts\python.exe tools\run.py --resetdata   # 备份→重建库→bootstrap→seed→内置剧本
```
`--resetdata` 备份在 `data/backups/resetdata-<时间>/`（db/WAL/SHM/scenario.json/manifest+sha256+photos/reports/logs 清单）；`--reset` 实测 60 历史/6 在场 → aborted6、out60 保留。

## 保留期清理

`config.yaml`/`config.production.yaml` 的 `retention` 段默认启用：`max_age_days=7`、`max_total_mb=2048`、`keep_recent_files=50`、`min_age_hours_for_capacity=24`、`interval_hours=6`、`run_on_startup=true`。`server/retention.py` 只扫描 `data/photos/{uploads,crops,camera}`（含视频抽帧子目录），不碰 `datasets`、`data/logs`、`data/reports`；只处理常见图片/视频后缀，每目录保留最新 50 个文件，容量清理不删 24h 内文件，`dry_run` 只统计。CLI：
```sh
.venv/bin/python tools/cleanup_photos.py --dry-run
.venv/bin/python tools/cleanup_photos.py --days 3 --max-mb 512 --keep-recent 20
.venv/bin/python tools/cleanup_photos.py --dry-run --json
```
服务启动清理一次并每 6h 后台执行；清理异常只记日志、不影响业务。生产启用前建议先 `--dry-run` 审核。测试 `tests/test_retention.py` 9 项。

.venv/bin/python tools/audit_consistency.py /path/to/copied/parking.db --out audit.json

发现重复在场/车位/支付或占用对账冲突时中止，按支付凭据和人工审计解决，不删除支付历史来满足索引。应用启动包含幂等表/列/唯一索引迁移并保留备份；布局迁移须确认当前PARKING_CONFIG指向副本。schema迁移后不要直接启动旧版写新库；回滚先停服务，恢复匹配版本的数据备份和代码。没有DB结构变更的UI修复可单独revert。

## Docker

从交付根目录构建（父目录同时含两套目录）：
```sh
docker build -f parking-system/Dockerfile -t parking-course .
docker run --rm -p 127.0.0.1:8000:8000 -v parking-data:/app/parking-system/data parking-course
```
镜像使用非root UID10001、单worker、healthcheck与独立data volume，默认demo=false。需要自定初始密码时通过目标环境设置PARKING_ADMIN_PASSWORD，仅对新库生效。原镜像源不可达时，可显式通过`--build-arg PARKING_BASE_IMAGE=...`指定已核验公共镜像；本机使用Google公共缓存的Python3.14-slim固定digest，记录见QA构建日志。持久卷需可由10001写入。容器不能当成多worker一致性证明。

## PyInstaller

在目标OS创建环境，再安装requirements.lock.txt和requirements-build.txt，执行：
```sh
python tools/build_native.py --output ../native-dist
```
输出目录必须不存在，避免覆盖已有交付。仅可在目标OS构建；macOS产物不能在Windows运行。输出为onedir，`parking-system/parking`（Windows目标为parking.exe）与assets_3d同级；完整保留目录，不只复制单个可执行文件。默认production配置，首启凭据见data。macOS本机arm64产物最终不传配置环境变量启动实测17.855秒（本机；此前并行负载下显式配置57.746秒），并非5秒启动承诺；未做公证/签名，不修改系统安全设置来运行。Windows/Intel Mac需要对应机器构建和验证。

## 常见失败

缺manifest/模型：`python tools/run.py --check`会明确失败；恢复原只读资产目录，不生成替代模型场景。端口占用：换--port。登录失败：确认使用的是新库随机密码还是演示账号。旧虚拟环境版本不对：在该环境显式安装锁文件，勿删除用户数据。3D资源失败：界面有重试按钮；可选壳失败显示回退，关键manifest失败会停止装配。数据库锁/并发异常：确认只运行一个应用worker。浏览器 E2E：`cd tools/e2e && npm ci` 并复用系统 Edge（`CHROMIUM_PATH`）或安装 Chromium；2026-11-06 既有 23 E2E **23/23 PASS**（1173.5s，exit0，`_qa_audit/repair_tasks_20261106/E2E/RESULTS.json`）。布局：当前固定只读 80 位/每区 20；C25/自定义坐标仍 409；**C25 预演/validate/layout_constraints/zone_capacity 已删除**（P2-07 C25 仍暂缓/部分）。手动派车/剧本：`/api/sim/plate-image`、`/api/sim/dispatch-plan`（同牌 409 duplicate_entry）、`/api/admin/scenario`（同牌时段重叠 422）；外部 140 模板/406 城市码；`demo-lpr` 18 张四类型。人工授权/黑名单：`/api/manual/authorize-entry|exit`、`/api/sim/blacklist-resolution`；裸抬杆仅物理。视频识别：`/api/recognize/video`；loopback RTSP 已实测，公网/鉴权未测。静态资产：manifest `static_colliders` 21，hash `sha256:593617b665b80945`。
