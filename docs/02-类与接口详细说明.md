# 类与接口详细说明（当前实现）

精确请求/响应 Schema 见同目录 `api-openapi.json`（由 `tools/export_openapi.py` 从当前 FastAPI app 生成；当前 78 paths / 82 operations）。运行中还可访问 `/docs`。以下清单由当前 FastAPI OpenAPI 与实现整理；`/api/admin/layout/validate` 与 `layout_constraints` 已删除。

## 权限与错误

公开：登录、health、public-config；demo-session仅在显式演示模式可用。其余API、模拟事件、照片/数据集图片与WS要求有效admin/operator身份。布局写入、名单、费率写入、道闸日志导出仅admin；operator可值班监控/缴费/人工操作。HTTP可使用Bearer或同源会话Cookie；WS使用子协议 `['v2','token.<JWT>']`，不要把JWT放URL。服务端校验过期/撤销/角色和Origin。

错误体一般为 `{error,message,detail}`：401未登录/失效，403权限/Origin，404无对象，409状态或幂等冲突，422参数/车牌，413上传过大，429限流。具体Schema和少数FastAPI标准错误以OpenAPI和实际响应为准。

## WS v2 / 会话

`/ws?features=v2&since=N&session=<id>`：welcome → snapshot或补发 → event/batch。封套 `{type:'event',seq,event_id,session_id,name,data,ts}`；seq全局单调，event_id唯一。补发REST `/api/events?since=N&limit=500` 必须循环到has_more=false；同步不能过滤类型来假定连续序号。客户端丢弃重复、检测缺口后补发/快照；旧会话先清理本地再hydrate。v1仍兼容但不具备v2持久补发保证，`server.ws_v2=false`回滚。

清场 `/api/demo/reset` 必须request_id；`force=false` 在占用/未决动作时返回409 `reset_unsafe`，`force=true` 跳过检查并把开放记录置 aborted（保留审计）、pending rejected、完成历史保留、车位释放、新会话/仿真归零；同请求重试返回相同结果，换参数重用ID返回409。soft终止当前会话记录，hard只清理符合条件的当前会话未付记录，历史NULL session和支付审计保留。

## 道闸

事件先barrier_cmd再barrier_state；cmd包含cmd_id/target/duration_sec，前端 `/sim/events/barrier_ack` 必须匹配gate/state/cmd_id。同cmd重试，不为重发生成新cmd；重复ack幂等、旧/错ack拒绝。STOPPED持久化当前开度，常开独立持久状态；occupied关杆409，落杆检测占用会复抬。动画和后端截止时间使用同一仿真时钟，后台tick为50ms。

## 识别、人工与寻车

`POST /api/recognize`（管理端上传识别演示）：multipart `file`（PNG/JPEG ≤5 MiB）或 `image_path`（限图库/照片目录），可选 `gate`；上传图/裁剪图写入 `data/photos/uploads`、`data/photos/crops`。阈值固定 **0.85**（`lpr.conf_threshold`，不沿用 0.95 严格成功位）；返回 `source="upload"`、`plate/plate_color/color`、`conf/overall_conf`、`candidates`、`evidence_url`、`image_path/image_url/plate_crop_path/plate_crop_url`、`image_source/image_synthetic`、`need_manual/success/message/source_status`、`elapsed_ms`、`image_metrics`、`recognition_log_id`。识别尝试（含人工/失败）写 `recognition_log`（`gate=upload`），管理端 `/api/recognition-logs` 可见；写日志失败仅告警、不阻断识别。**不做 expected 匹配、绝不触发入场/记录/车位/道闸**；管理端 `/admin/#/recognize` 页面以标题/“识别演示”标签说明只识别、不产生入场/放行；无固定 banner。

`POST /sim/events/arrived-frame`（3D 仿真主流程）：multipart `vehicle_id`、`gate`（in/out）、`expected_plate`（可选）、`sim_ts`（可选）、`image`（PNG/JPEG ≤5 MiB）。后端保存到 `data/photos/camera/`，发布 `VehicleArrived(source="sim_camera", expected_plate=...)`，同步返回 `{ok, vehicle_id, gate, expected_plate, image_path, image_url, recognition}`；`recognition` 含 plate/color/conf/need_manual/candidates/message/reason/image_url/plate_crop_url/source/expected_plate/plate_match。WS `plate_recognized` 同步携带 `source`、`expected_plate`、`plate_match`、`image_url/plate_crop_url/image_source/image_synthetic`。

expected 决策只对 `source=sim_camera` 生效：识别串规范化后等于 `expected_plate` 且 `conf ≥ lpr.sim_conf_threshold`（默认 **0.85**）时自动通过（`need_manual=False, reason=expected_match`）；不一致/缺失/低于阈值转人工（`expected_mismatch`/`expected_missing`/`low_conf`）。旧 `POST /sim/events/arrived`（JSON、image_path 图库模式）保留回退，可带 `expected_plate/source`；`?camrec=0` 可强制回退。**上传路径没有 expected，只展示结果**。

统一识别管线：原图为主识别，低置信/无结果时尝试 CLAHE、2×、±3°、bbox 裁剪等变体（`lpr.pipeline_variants=true`，最多 `pipeline_max_variants=6`）并取最高置信；3D 相机与上传共用同一 HyperLPR3 输出结构。`/api/recognize/frames` 仍支持上传 2–5 张不同内容帧并融合（冲突转人工、不会直接抬杆；`lpr.multiframe_enabled=false` 可关闭；不直接解码视频），融合后写一条 `recognition_log` 并返回 `recognition_log_id`。3D HUD/管理端监控的"识别输入"卡片显示相机截图/裁剪/conf/expected/匹配；历史事件无新字段时按 `image_path` 回退。

`POST /api/recognize/video`（P3-06，视频源识别）：JSON `path` / `rtsp_url` / `source` 三选一，另有 `gate`、`frames`（2–5）、`interval`（0–10s）、`timeout_sec`（1–60）；本地路径限 `data/photos`、`data` 或项目根内，文件 ≤50 MiB；使用 OpenCV `VideoCapture` 按时间位置抽 2–5 帧，调用现有 `recognize_frames` 融合并写 `recognition_log`。返回 `source/source_type(file|rtsp)/gate/batch_id/frames[]/fused/video{...}/recognition_log_id`；帧存 `data/photos/camera/video_<batch>/`。**不进入入场/放行/expected 决策**；本地视频 smoke 通过；**loopback RTSP 已实测**（便携 ffmpeg+mediamtx 推流，API/CLI 识别 湘N7D071；首次首帧约 20.5s 后重试成功，API 22.3–24.4s/CLI 24.9–26.1s），**公网/鉴权 RTSP 未测**；依赖 OpenCV FFmpeg 后端/网络/鉴权。CLI：`tools/recognize_video.py`。

真实字符复核（可选）：`lpr.real_char_verify` 默认 `false`；开启时在 HyperLPR3 输出后逐字复核，任一位置 top-1 不一致转人工、不降低 0.95 阈值；真实数据域差异下过于保守，故默认关闭，不影响演示主流程。

`/api/recognize/gallery`仅投影固定18条`datasets/demo-lpr`演示样例元数据，图片仍需登录；任意dataset JSON/ZIP不能通过静态挂载读出。`/api/find-car?plate=`精确查当前在场：规范化车牌，404无记录、422语法、409车位占用不一致；无车位临时记录located=false，不虚构坐标。

人工确认/修正/拒绝/超时记录审计。无记录出场支持max_duration/manual/free；人工结算charge/free/void/manual_time、request_id幂等，免费支付0、作废abnormal不伪造收入。所有自动/人工准入统一语法校验。
