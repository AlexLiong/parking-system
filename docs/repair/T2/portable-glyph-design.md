# T2 兼容渲染的跨平台补修
复现：Docker Linux arm64 无系统 CJK，6 个旧 render/NCC 回归被跳过。新 HyperLPR 与样式基准不受影响，但旧 render 仍使用自选字体，不满足原 Prompt。基线为 P3-02 打包提交。
方案：按已锁定 MIT 源提交提取 140/green 全字符字形与蓝/小绿/大绿底板，存成本地 NPZ+SHA/许可；render 保留 PlateFonts/render_plate/render_char_template 接口，内部只用字形掩膜与标准排版，拒绝系统字体注入。模板从同字形归一化生成，随包提交；旧图库仅兼容，不再用于首车演示与 PR-2。原省份复核 NPZ 不变，故样式基准应不变。
验收：Mac/Linux 全量pytest不skip；模板与粗笔画相关性、端到端识别、无错误自动放行保持原断言；新图库/基准数据不改；资源SHA与许可；实际模型资源只读。
若新渲染触发旧定位/分割缺陷，保留失败并在本任务修复，不降低断言。
重做结果：规范底板有边框和铆钉，旧 fallback 从灰度图重新取内容会把已清除的边框重新带回；中文不相连偏旁被高度过滤提前删除。采用标准单行牌字符带（上下15%、左右2.5%留白）去除牌框/铆钉、偏旁先按小间距合并再过滤、fallback复用已清理二值图。模板迷你牌保持字符纵向位置25..115/140，与真实比例一致。全部失败尝试回退后重做，原测试断言未改。
