# P2-15 识别修正回写检查点

现有 `recognition_log` 已有不可变原识别 `plate` 和待用的 `manual_corrected/corrected_plate` 字段，但无 `vehicle_id` 或待办 ID。直接按车牌匹配停车记录可能改错车，因此本检查点只回写识别日志，并在 `op_log` 留下原值、前次修正值、新值和操作者。管理员在识别日志页操作；未授权请求拒绝，非法普通/新能源号牌拒绝。相同修正幂等，不重复写审计；更改修正值另记一次审计。

`POST /api/recognition-logs/{id}/correct` 请求 `{plate}`，返回更新后的日志视图。`plate` 原值不覆盖。数据库无新列，旧库无需迁移。完整 P2-15 仍依赖 P1-02 持久人工待办提供 `vehicle_id` 与 `recognition_log_id` 的明确关联，届时确认动作才能同时提交待办、识别日志与进出场业务；本接口不单独抬杆或修改在场记录。

验证：管理员可修正蓝/绿牌，刷新仍可见原值和修正值；非法车牌/未授权/不存在 ID 无写入；重复同值幂等；每次变更有 op_log。回滚单独撤销接口与 UI 提交，已写的修正记录保留供审计，不做破坏性数据回滚。
