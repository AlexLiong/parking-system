# T2 真实照片评测协议

## 冻结测试集

只接受带来源、许可、真实摄影核验、车牌号、车牌框/四角点和分组标签的真实照片。独立列出清晰、污损、近景、整车、倾斜、夜间/逆光、模糊、低分辨率、蓝牌及绿牌样本数。相互重叠的子集允许重复计数，但每项分母必须公开。测试图及同车牌/同序列照片不参与训练或调参。

## 指标

- 整牌完全正确率：预测字符串与真值完全一致的图数 / 有效图数。PR-2 清晰子集 >=95%，污损子集 >=85%。报告每项分子、分母及置信区间；不能用字符准确率替代。
- 字符准确率：按位置统计正确字符数，同时报告长度错误；不要让 `zip(truth, pred)` 静默忽略缺字。另报检测 IoU>0.7、角点误差、颜色/类型准确率和整体端到端整牌率。
- 安全与业务：错误自动放行数量和比例、正确自动放行比例、转人工比例、故障误判率；错误自动放行逐张列出。低置信应进入可持久化人工待办，不能算作识别正确。
- 延迟：CPU 推理 p50/p95、输入分辨率、设备/系统、模型 SHA-256、运行次数和冷/热启动；Windows/macOS 使用同一 ONNX 和固定预处理做一致性核验。

## 运行与复现

评测器只接收冻结清单，逐张输出输入 SHA-256、真值、检测框/角点、预测及置信度、业务判定、耗时和失败原因到 JSONL；汇总 JSON/Markdown。所有失败样本保留可追溯 ID。样本不存在、标签不合法或实际图像与 hash 不符时失败退出。`tools/eval_lpr.py --dataset datasets/plates` 仅是旧合成基线，**不能用作本协议的 PR-2 结果**。

当前没有符合协议的真实测试集，所以无真实集成绩、无达标结论。取得并冻结数据后才实现评测器并运行。
