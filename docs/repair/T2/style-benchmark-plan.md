# T2 号牌样式与干扰基准

2026-10-20 用户调整当前目标：先提高不同车牌样式、角度、光照、颜色下的识别表现，暂不以真实照片占训练集至少 70% 阻塞研发。合成基准按 synthetic 标识，结果不冒充真实照片 PR-2。

使用指定 MIT 项目固定提交的原始字形和蓝牌、小型新能源、大型新能源底板。每种版式固定种子生成 24 个车牌，每牌覆盖正视、左右侧倾、俯仰、暗光、眩光、暖色、冷色和轻污损模糊，共 648 张。角点按投影精确生成；验证/测试按原始车牌分组，各 324 张；同车牌所有增强仅进入同一 split。

先冻结清单和原模型基线，再针对验证集失败原因改进；测试集不用于阈值或预处理选择。报告整牌、错误自动通过、转人工及各样式/条件分母。保留 EasyPR 39 张实拍测试作为回归，降低检测/字符误判时不得用标签决定推理或降低自动通过规则。

## 验证集决策（实现冻结）

验证集原模型 306/324，错误自动通过 2/324。诊断表明定位已成功，失败主要为省份字、绿牌 D/0，以及关键点裁剪偏移。验证集比较了关键点/颜色轮廓裁剪、灰度、CLAHE 与边距；简单多数投票会将正确原始结果改错，因此没有采用。最终使用仅在检测框附近提取的凸四边形颜色边界，透视校正后做原色/灰度/LAB 亮度 CLAHE 三次 CTC。语法有效且至少两次重复的结果按平均置信度排序；原始语法有效时必须同位数、分数更高才可替换。任何改写都转人工；原始结果自动通过要求另一个高置信结果支持且无其他高置信冲突。不降低原 0.95 门槛。

配置 `lpr.style_refinement` 默认 true，可设 false 恢复单次推理，基准 `--baseline` 同样关闭。推理不读取生成器文件、标签、清单或条件类型。不重新训练公开权重，因此本次称为推理增强与合成基准，不能声称训练集比例或 PR-2 全量达标。颜色轮廓不完整时保留原文字候选并转人工，避免提高自动通过数量掩盖不确定性。最终测试集在上述规则冻结后运行；错误及剩余省份字失败全部列入报告。

## 省份字辅助核验方案（仅以验证集选择）

第一次独立合成测试：单次模型 306/324，颜色多裁剪 305/324，错误自动通过 1→0；因此不能声称整牌率提升。继续以原验证集开发省份字核验，并完整保留第一次测试结果。省份字取自指定项目蓝牌 `140_*` 与 `green_*` 原始字形，归一化后与颜色透视裁剪的第一字区域比较。验证集诊断：相似度≥0.6 且第一/第二名差距≥0.08 的 255 个字均正确；最终采用更保守的相似度≥0.65、间隔≥0.15。辅助字形只改省份字或消除前导重复汉字；所有改写强制人工。模板分数不冒充 CTC 概率。对实拍验证集进行回归后再冻结实现；最终新增独立随机种子、不同牌号的测试集，原测试作为公开回归集保留，不再用于调参。

省份字核验在原验证集整牌 324/324、错误自动通过 0；EasyPR 实拍验证仍 40/43、错误自动通过 0。2026-10-20 在此冻结全部参数与推理实现。新独立测试 `style-benchmark-v2` 使用 seed=20261021、每版式32个牌，测试16个牌/版式×9条件=432张；与先前所有牌号做不相交校验。其测试结果不得反向用于修改本版阈值。上述合成成绩对同一原字形库有效，不能代表全部实拍字体、距离或相机。
