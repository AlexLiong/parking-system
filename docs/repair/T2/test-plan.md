# T2 识别事件与摄像头语义验证

1. 同一闸连续超过阈值的低置信图像：有待人工事件，camera incident 不创建。
2. 连续无图/不可读图像达到阈值：camera incident 创建一次，闸口进入人工降级；管理员恢复后计数清零。
3. 一次图像源成功夹在源失败之间：计数重置；重复进场/满位等业务拒绝不参与计数。
4. WS 事件保留旧字段，新增机器可读 `reason` 和可见 `message`；重放/快照仍可序列化。
5. 完整 Python 与 Node route 回归，隔离测试数据库；不在主演示库中注入故障。
6. 连续近乎纯黑/纯白帧达到阈值：转人工、登记单个 camera incident；非均匀的模糊图只按识别失败处理。
7. 管理员状态查询显示故障、计数和 incident ID；未登录被拒绝，`/reset` 恢复并清零；识别 REST 提供 `source_status/image_metrics`。
