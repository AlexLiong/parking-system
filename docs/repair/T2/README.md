# T2 车牌识别 v2：准备与检查点

关联 C-02、C-06、C-07、P1-02、P1-11、P1-07、P2-15、P3-06。目标是以真实中国大陆车牌照片训练和评测识别模型，并让低置信、失败和摄像头故障在业务链路中可区分、可处理。

## 本轮最终覆盖说明

按用户最新指令，本轮暂不以实拍训练≥70%阻塞。最终采用指定MIT源字形/底板构造蓝/小绿/大绿及9种条件，独立v2测试432张整牌正确432、错误自动放行0、人工46。EasyPR测试38/39保持，错误自动0，保守省份核验使人工33/39（此前13/39）。本轮没有重新训练公开模型，PR-2完整真实分组仍受限；以下历史阶段数字须按此最终检查点理解。

## 当前状态

**T2 部分完成，PR-2 数据检查点仍未通过。** 输入包 `datasets/plates` 的 160 张图均由项目合成器生成，不能用于 PR-2 真实照片指标。现有 `tools/eval_lpr.py` 的默认模式也是在线合成。2026-10-20 在该合成集上得到整牌 126/160（78.8%）、字符 1040/1200（86.7%）、错误自动放行 0/160；这些数字只描述旧实现的合成集表现。

CCPD 官方仓库提供 MIT 许可、文件名标注规范和下载链接，但完整图像位于 Google Drive/百度网盘；仓库仅有 5 张演示照片。EasyPR 的 GDTS 已从官方仓库获取 256 张图片，按 GDSL 仅用于本非商业学习项目。结构化导入后 249 张符合当前普通号牌语法，按车牌分组切分为训练 167、验证 43、测试 39；还有 7 张因主框缺失/号牌类型超出当前规则而排除。EasyPR 不含可用的四角点/清晰污损与近景整车人工分组，也未覆盖新能源绿牌，因此还不是最终 PR-2 验收集。

已接入 Apache-2.0 HyperLPR3 本地 ONNX 模型；真实照片走模型，项目自带合成演示图库保留模板路径。模型或权重不可用时，真实照片转人工，不回退到合成模板。EasyPR 冻结测试集上的整牌成绩从旧模板 0/39 提升到 38/39，错误自动放行 0/39，最终33/39 转人工（接入阶段13/39）；验证集为 40/43，错误自动放行 0/43。该数字只对应 EasyPR 普通蓝牌子集，不等于 PR-2 清晰/污损达标。

已另行清点 treeandgrass MIT 图包：1223 个图片文件中 1222 个可解码，去重后 1201 张。抽样确有整车和近距离车牌拍摄，但逐张真实性、标签和来源尚未审核，无框/四角点；全部留在候选清单，不用于声称训练比例或 PR-2 成绩。识别结果事件现已区分缺图、损坏图、黑屏/白屏、低置信、模型异常和业务拒绝；监控端和仿真 HUD 可显示拒绝消息。摄像头看门狗只对连续图像源失败登记故障，管理员可查询状态并重置。

P1-02 已增加按会话和车辆关联的持久人工确认队列：入口确认在事务内修正识别日志、创建停车记录并占位，提交后才发道闸命令；出口确认只核验在场记录并报价。拒绝、超时、清场会关闭待办，不触发放行。管理端实时监控页可处理待办，仿真端接收状态反馈。P2-15 的独立日志修正仍只改日志；旧日志没有车次 ID，不会据此改停车记录或抬杆。

P1-10 已在业务授权边界统一蓝/绿牌语法校验。非法人工牌拒绝入库；自动识别出的非法候选带原识别日志进入人工待办，不自动开杆。

P3-06 已提供 `POST /api/recognize/frames` 连续帧批量上传入口，2 至 5 张 JPEG/PNG，单张最多 5 MiB，重复图哈希拒绝；逐帧保留识别日志和结果，融合结果要求至少两帧独立可信、车牌与颜色一致且语法有效。接口不触发道闸，`lpr.multiframe_enabled` 可关闭。调用方仍须保证同一车辆的短时间取帧；当前不直接读取 RTSP 或视频编码文件，也没有独立真实多帧评测，因此这部分只完成上传接口和安全融合，不能据此宣称 PR-2 达标。详见 [multiframe-design.md](multiframe-design.md)。

- [data-plan.md](data-plan.md)：来源、许可、隐私、标注、切分及真实/合成比例。
- [eval-plan.md](eval-plan.md)：真实集指标、分组、失败样本与防数据泄漏规则。

- 扩充有许可且可读取的真实照片；人工审计每张图的来源、标签、角度/污损、近景/整车分组和独立绿色车牌来源，建立最终冻结测试集。
- 原始长期目标：训练集真实照片占比至少 70%，目标 80%；用户本轮暂缓这一阻塞条件。近景和整车均为真实拍摄，不能靠合成图或从同一整车照片裁切来冒充独立近景来源。
- 完成以真实照片为主体的可复现训练；当前接入的是公开预训练模型，原训练照片比例未被证明，不能代替本项。最终须在符合分组协议的真实照片测试集达到清晰整牌 >=95%、污损整牌 >=85%。未达到则如实报告未完成。
