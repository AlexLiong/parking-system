# C-10 运行时对向共线收尾设计
全静态OBB安全版本使用支路中心转向，原manifest“对向共用0”不能套用。进一步核对160条计划：长支路出场同翼同向，真正反向重合位于±6m分岔区。主因相反方向转向统一使用同一z中心，以及非边界出库强制中心线时保留了原车道连接的往返小段。
方案：在只读6.5m分岔净宽内为东西方向分别设置中心±0.20m转向线，相向主段不再共线；不是移动/缩放模型，保持全部碰撞体。非边界出库直接以实际出口方向的安全中心接到分岔横段，消除原车道来回，仍保持最长车完整退出隔离带后转向。现有W翼/JT交叉互斥保留，因为扫掠体仍交叉，不能因中心线分离而取消安全锁。
关键验证：以运行时planEntry/Exit access=false的全部线段比较反向共线重合，零容差目标1e-6；同时160条含机动的van全OBB静态检测、20车600秒、至少3进2出同时、C三车和邻位、原route/node回归。不得通过删除碰撞体或降低断言通过。若候选失败只回退本任务文件；UI/正在进行的最终集成状态保留。
