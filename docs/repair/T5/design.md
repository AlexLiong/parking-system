# T5 运行时安全与验证体系

基线27a6a91。此前traffic-safety测试仅覆盖队列/状态，不能代替实际GLB与静态场地证明。独立审计以真实manifest全部静态体、van(5.2×2m)OBB、Vehicle实际30Hz积分采样160条入出路径，发现160条均碰median_m/median_s，8条另触墙。原因：图中turn边为弦线，车辆转向时后角扫过隔离带；边界倒车曲线末段横移过晚；调度_staticHit直接忽略低矮硬体和目标车位附近墙体掩盖问题。资产保持只读。

方案：运行时safeTurns选项将图的转向弦线改成开口内的轴向连接，保持manifest图/端点/基线路网统计不变；中央交叉使用开口中心通道确保最长车尾退出隔离带再转向。边界入库延长终点切线，避免靠墙横向旋转；以全OBB扫掠验证路径，不能靠删除碰撞体通过。调度用完整OBB静态检测，移除旧跳过逻辑；车辆每步预测，出现障碍回退当步并停车，禁止已经碰撞后才拦后车。已知资产边界R-04单列，不扩大豁免范围。

测试矩阵：route原32；车辆/调度至少16实质用例（运动、反向、限速、状态、八车队列、精确授权、刷新/清场、碰撞）；20车600s、8同刻、C三车、同时进出；静态体OBB/SAT与Z7实际窗口口径；浏览器真实GLB全链路/防砸/10min运行；后端全量、WS、20/50并发、10万条统计。CI统一入口shell与PowerShell。__SIM__.dump必须可JSON序列化并列出pending/queue/reservations/vehicles。硬件FPS与真实PR-2、2h soak/Windows若未执行明确为受限，不能以模拟时间替代墙钟时间。

实施顺序：先修并验证静态路径，再做成批交通/完整出口、测试入口和基准、真实浏览器长运行。每发现失败只推进当前专项，不以修改资产、删断言或绕过障碍通过。现有输入行尾差异不归本任务，提交时仅提交有效代码差异。

实测补充：10万条历史年统计基线3.958s（同机隔离库，日0.155/月0.499/分页0.023s），超过2s。统计原先多次实例化全字段ORM对象。采用仓储新增投影查询，仅取日期/时长/金额参与统计，保留所有API、业务时区/临时记录口径与原仓储接口，不靠缓存减少测试数据或改变查询目标。

最终调度决策：全OBB安全路径在支路中心通过，运行时相向路径有共享段，因此增加W_A/B/C/D整翼互斥与JT_N/JT_S交叉口互斥；不可将manifest图的对向共用0m指标套用于运行时。连续接触区在移动前原子申请整包，失败释放本轮新申请；已有物理占用不能被过期窗口或优先级抢占。路口遵守同车道物理前后顺序，避免后车先拿锁。边界车位入库切线3m，非边界出库先直达支路中心。代价是吞吐量降低，安全优先。

统计最终方案：SQL投影仍超过2s后，现代固定业务时区采用SQLite按本地日分组（UTC、上海/重庆/香港且1993年后），其他地区/历史/DST使用原ZoneInfo精确回退。十万条年统计1.34–1.68s，等价日界测试覆盖午夜和回退分支。
