# C-10 支路净距收尾
61622b2已消除运行时对向共线，仍需保留原需求对向车道1.25m净距。中心出库虽由W互斥保障不撞，但不能把原图1.25m数值套到中心出库路线。
非边界车选择出口方向至少8m之后的原manifest车道节点作为接入点，保持先直出到道路中心再用低曲率Bezier并入既定出口车道；后续道路回到原出口车道，与入口相隔3.25m（van净距1.25m）。离路口太近不足8m的车位，其整个出库机动在Z7/JT保护下以Bezier直接进入分岔转向线，circulation从分岔开始；不为凑指标把长路段移入交叉区。边界车位保留已验证的出库曲线。冲突区与只读资产不变，W/JT互斥保留。
验证新增实际道路plan的区外对向车道中心距与穿越点，原共线审计不排除任何冲突区。160长车全静态OBB、20车/600秒、同刻3进2出、C三车、原Node回归及浏览器链路。失败只恢复本专项到61622b2，不带失败候选进入交付。

首轮全占用邻车扫掠失败已回退：入口分岔结束的90度横移会扫到最靠路口已停van，部分短程出库在尚未完全离开车位时转弯、边界出库沿旧车道横移会靠近对面已停van。第二轮将入口分岔内横移换成水平切线Bezier；出库统一先到支路中心（边界保留原避墙Bezier），再并线/接入分岔，短程不在两排车之间提早转向。测试补全79个其他车位满停van条件，曲线道路审计按64段离散，不能跳过曲线。

最终候选6：非边界入库倒车弧线L=1.0m，满停79邻车最小净距0.39627245m（要求≥0.358m）；所有160实际道路计划反向共线0、对向中心距3.25m/van净距1.25m、区外交叉0。20车/同时/C三车、160静态路线、36+24Node均通过。各失败候选保存后回退重做，未降低断言。
