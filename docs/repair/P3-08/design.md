# P3-08 反向寻车
FR-10.4 要求输入完整车牌显示当前车位与入场照片。当前只能在记录模糊检索间接查询，缺专页/API。
采用鉴权后的精确车牌查询 GET /api/find-car?plate=，复用语法规范化与当前在场记录；位置以当下DB车位为准，对账不一致409；无在场404、非法422，无车位临时记录返回located=false，不虚构位置。只读事务内读记录/车位，返回入场时间/照片/车位/分区/坐标/明确文字指引，地图使用现有布局数据。
页面 #/find-car：标签完整的表单、Enter提交、加载/空态/错误、入场照片、按车位坐标生成无依赖SVG图并突出目标；标明入口、东/西侧与北/南区域。基于现有场地导视定位，不宣称提供未经验证的无障碍步行路线。
不选择复用模糊 records API：相近牌/历史多条容易误选，且无法表达临时无车位、车位对账状态。无DDL、新API兼容旧记录。
测试：无授权、规范化蓝/绿、已离场、近似牌不命中、无照片、无车位、占用不一致；真实界面键盘查询与照片/目标车位验证。安全回滚revert，无DB迁移。
