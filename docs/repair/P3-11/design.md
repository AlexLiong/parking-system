# P3-11 可用性、移动适配与关键文案
基线b7dfd8e。静态复现：720px隐藏整个侧栏，无替代导航；modal仅Escape，缺role/label/焦点约束和恢复；多数label与输入没有关联；图库只能鼠标点击；浅色次要文本、彩色按钮对比度不足。
方案：共享DOM构建器在构建带标签表单时关联唯一ID，不使用全局观察器；模态对话框使用role/aria-modal/标题引用，焦点循环、顶层Escape、关闭恢复，背景inert，修正直接删遮罩的监听泄露。移动端提供带标签的原生页面选择器，主区skip link与当前导航语义；网格minmax(0,1fr)、内部表格横向滚动，避免页面整体溢出。
关键导航/通用按钮/登录文案集中于zh-CN/en词典，持久化导航语言；金额/日期用Intl且保留业务时区，业务长文案仍中文，不宣称整站全翻译。颜色提升到普通文本目标4.5:1，明显focus-visible、减少动画偏好。图库与上传键盘可达，图片替代文本。
验证：登录/监控/记录/识别/寻车至少5页，390/768宽度无页面横向溢出、有可用导航；标签、Tab循环、Escape、焦点恢复、错误/空态及切换导航语言。真实浏览器截图、日志；不把局部检查等同WCAG认证。无数据/资产迁移，独立revert回滚。
